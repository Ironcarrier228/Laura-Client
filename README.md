## ✨ Модули

<details>
<summary><b>⚔️ Combat</b></summary>

<br>

| Модуль | Описание |
|--------|----------|
| **KillAura** | Автоматическая атака с 6 режимами ротации, обходы под сервера |
| **ElytraTarget** | Преследование игроков на элитре с авто-фейерверками |
| **BowAimbot** | Автоприцел для лука с баллистическими расчётами |
| **AutoPotion** | Автоматическое использование зелий |

</details>

<details>
<summary><b>👁️ Render</b></summary>

<br>

| Модуль | Описание |
|--------|----------|
| **ESP** | Подсветка игроков сквозь стены (Box / 2D / Skeleton / Glow) |
| **Tracers** | Линии к игрокам с цветовыми режимами |
| **TargetHUD** | Отображение HP и брони текущей цели |
| **Chams** | Цветная подсветка игроков сквозь стены |
| **FullBright** | Полная яркость (Gamma / Potion / Table) |

</details>

<details>
<summary><b>🏃 Movement</b></summary>

<br>

| Модуль | Описание |
|--------|----------|
| **ElytraTarget** | Управление полётом на элитре |

</details>

## 🔑 Активация

Клиент использует **KeyAuth** для проверки лицензий.

1. Получи ключ у продавца
2. Запусти лоадер
3. Введи ключ в поле активации
4. Готово!

> 💬 Купить ключ: [Discord](https://discord.gg/CY2uFGKr)

---

## 📋 Требования

- **OS:** Windows 10 / 11
- **Java:** 17+ ([скачать](https://adoptium.net))
- **RAM:** минимум 2 GB
- **Minecraft:** 1.16.5

---

## 📦 Установка

```
1. Скачай LauraLoader.exe
2. Запусти от имени администратора
3. Введи ключ активации
4. Лоадер автоматически скачает клиент
5. Укажи нужный объём RAM
6. Minecraft запустится автоматически!
```

---

## 🔄 Авто-обновление

Лоадер **автоматически проверяет обновления** `client.jar` при каждом запуске.

```
[Обновление] Проверка обновлений client.jar...
[Обновление] Найдено обновление! d00589a → a1b2c3d
[Обновление] Скачивание нового client.jar...
[Обновление] client.jar успешно обновлён ✓
```

## ⚙️ KillAura — Режимы ротации

| Режим | Описание |
|-------|----------|
| **Плавная** | Стандартная плавная ротация |
| **Резкая** | Быстрая резкая ротация (+50% скорость) |
| **Snap** | Мгновенная ротация |
| **Интелектуальная** | Адаптируется под расстояние |
| **Matrix** | Случайная ротация с микро-дрожанием |
| **Экспоненциальная** | Ускоряется при приближении к цели |
